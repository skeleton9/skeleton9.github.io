PHYSICAL AI · CONSUMER OPPORTUNITIES

Microduck × C端应用机会地图

真正的新机会，不只是“机器人多几个功能”，而是让 AI 从屏幕里的聊天对象，变成一个有身体、有位置、会行动、会成长的现实世界角色。
关键问题：人为什么愿意让一个 AI 长期存在于自己的现实生活里？

从 App 时代到 Character 时代

过去Hardware → OS → App
未来Body → Agent OS → Character → Skill
交互变化“打开 App” → “让我的 AI 学会 / 帮我 / 陪我”
消费级 Physical AI 的核心，不是工具感，而是存在感、关系感与成长感。

六类 C 端应用形态

从“最容易形成情感留存”到“最有平台潜力”，可以分成六个方向。

01

AI 宠物

核心不是干活，而是陪你生活。每一只机器人因为不同主人、互动和经历，逐渐形成不同性格与记忆。

长期记忆Personality主动行为成长系统
机会评级 ★★★★★
02

儿童 AI Buddy

不是“机器人老师”，而是孩子的伙伴。尤其有意思的是让孩子“教 AI”，把编程、逻辑、探索藏进养成体验里。

陪玩任务探索AI启蒙Pokémon式成长
机会评级 ★★★★★
03

现实世界游戏机

把电子游戏从屏幕搬到现实空间：赛车、足球、寻宝、躲避、多人协作，机器人本体变成 Console。

Physical Game多人互动Game PackSkill Store
机会评级 ★★★★☆
04

AI 桌面生命

Agent 有了实体存在感。它能在你工作时提醒、记录、陪伴、督促，而不是像普通通知那样被轻易忽略。

桌面助手Habit CoachIdea CapturePhysical Avatar
机会评级 ★★★★☆
05

Family AI

认识家庭成员、保存共同记忆、参与生日与日常事件。身体可以替换，但“它”通过云端记忆持续存在。

Family Memory家庭关系照片/故事长期资产
长期价值 ★★★★★
06

老人 Companion

前台是宠物与陪伴，后台才是提醒、家庭连接和轻度照护。避免把产品做成“我老了/我是病人”的标签。

陪伴提醒家庭连接子女付费
机会评级 ★★★★☆

真正驱动留存的四件事

Character可爱、有性格、有辨识度
Memory记得你、记得家庭、记得过去
Agency会主动做事，而不是永远等命令
Growth越养越懂你，越用越会东西

商业模式

Hardware$199–499 作为入口
Membership$5–20/月 AI 与记忆能力
ContentVoice / Skin / Personality
MarketplaceSkill / Game / Character 分成

推荐切入路径：AI Pet Platform

先解决“为什么用户喜欢它”，再解决“它还能干什么”。

1. 可爱角色先产生拥有欲与传播力
2. 关系记忆让它越来越懂主人
3. 成长机制Day 1 与 Day 100 明显不同
4. Skill Packs舞蹈 / 游戏 / 学习 / 健身
5. Platform开发者创造新角色与新行为

不建议一开始做

通用家庭机器人场景太散、硬件太重、成本太高。
机器人版 ChatGPT如果只有语音聊天，身体没有创造真正差异。
纯工具型机器人用户很容易直接拿手机替代，缺少持续关系。

最值得押注的产品判断

先让用户因为“它很可爱、像一个生命”而买它，再因为“它越来越懂我、越来越会东西”而留下来并持续付费。

不是卖一只机器人，而是在卖一段会复利的关系。

一句话总结

Microduck 代表的 C 端机会，不在“更强的机器人功能”，而在新的产品范式：让 AI 变成一个现实世界中的 Character，并通过记忆、成长与技能形成长期关系。

Character × Memory × Skill × Physical World
